# MM COM AGENCE - ERP & Gestion de Facturation

Application ERP Desktop développée en Python et PyQt6 pour la gestion commerciale et la facturation (clients, devis, factures, règlements, exports PDF).

## 🚀 Fonctionnalités

- **Tableau de bord** : Vue d'ensemble des statistiques et indicateurs clés.
- **Gestion des Clients** : Création, modification et suivi des fiches clients.
- **Devis & Factures** : Création rapide de devis et conversion en factures.
- **Génération PDF** : Export professionnel des devis et factures avec ReportLab.
- **Gestion des Règlements** : Suivi des paiements et des états d'impayés.
- **Base de données SQLite** : Stockage local fiable et rapide.

## 🛠️ Prérequis & Installation

### 1. Cloner le projet
```bash
git clone https://github.com/zaid03mh/gestion-facturation-mmcom.git
cd gestion-facturation-mmcom
```

### 2. Installer les dépendances
```bash
pip install -r requirements.txt
```

### 3. Lancer l'application
```bash
python mmcom_erp.py
```

## 📋 Technologies utilisées
- **Python 3.11+**
- **PyQt6** (Interface graphique)
- **SQLite3** (Base de données locale)
- **ReportLab** (Moteur de génération PDF)
